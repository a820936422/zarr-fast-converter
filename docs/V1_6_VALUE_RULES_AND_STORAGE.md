# v1.6.0 数值规则、压缩与磁盘遥测

## 数值替换规则

采样前规则在缺测值掩码完成后、xESMF 调用前执行；采样后规则在 xESMF 结果写入前执行。
字面量规则融合在现有空间 tile 中，不增加完整中间数据。采样后规则若引用统计量，则先写入
未修改的重采样 staging，冻结按变量统计结果，再按 Zarr chunk 第二遍替换。

规则使用从上到下首个匹配生效的语义，缺测值和非有限值默认不匹配。表达式只允许数值、
统计量、括号、基本算术和 `abs`、`ceil`、`floor`；禁止属性访问、导入和任意函数调用。

`auto` 统计策略对不超过 128 MiB 的输入和目标逻辑数据执行精确统计，较大任务采用最多
250000 个确定性采样值。`sample` 始终采样，`exact` 明确请求全量统计，会实体化单个变量的
全部数值，因此仅建议用于已确认内存可承受的小数据。解析后的规则、统计模式和统计值写入
manifest schema v4 的配置和阶段指标。

## 压缩配置

旧 `fast`、`balanced`、`maximum` profile 保持兼容。显式配置支持：

- `blosc-zstd`、`blosc-lz4`、`blosc-lz4hc`、`blosc-zlib`；
- 原生 Zarr v3 `zstd` 和 `gzip`；
- codec 对应的合法压缩等级；
- Blosc 的 `auto`、`noshuffle`、`shuffle`、`bitshuffle`。

`auto` 对整数使用 bitshuffle，对浮点使用字节 shuffle，其他类型不使用 shuffle。坐标继续
使用低成本 Zstd level 1，避免让小型坐标数组承担数据变量的高压缩开销。

## 任务磁盘遥测

任务启动时根据输入文件、临时根和输出父目录解析挂载点。同一设备上的角色会合并，任务中心
只显示涉及的设备，并展示空间、设备读取速率和设备写入速率。任务进程 I/O 与设备整体 I/O
分别计算；设备统计不可用时不影响主数据任务。
