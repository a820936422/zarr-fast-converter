## 1. v1.8.0 已完成内容（基线）

- WorkerPool 全路径接入：direct_write、filename 模式、inspection、重分块两阶段与调参、重采样空间并行。
- 跨设备/同设备 HDD 读写阶段分离：`--staging-root`、跨文件系统复制发布、filename `--phase-batch`。
- PipelineFusion 单遍流式：eligible 路径 `write_amplification=1.0`，`--no-fusion` 保留磁盘 checkpoint/恢复。
- OnlineController 扩展到重分块与重采样，pipeline manifest 聚合 `online_adjustments`。
- PerformanceModel 默认启用与剪枝；HardwareProfile 调度集成。
- native NetCDF conversion 支持未打包标准整数。
- HDF-EOS Grid / Swath 低层读取与 filename 模式转换覆盖。
- native conservative/conservative_normed 球面 cell-area overlap 与确定性边界触碰规则，Python/xESMF 路径同规则对齐；v180 真实数据 acceptance 9/9 通过。
- 真实数据 scaling 基准基础设施与 smoke 门禁。
- 版本提升至 1.8.1，v1.8.0 完成项已收敛进 `MAINTENANCE.md` 版本历史。

## 3. 待办清单

### 3.1 测试数据源（数据备份）

数据根目录为 `/run/media/owen/HDD/数据备份/`，以下数据集可用于 v1.8.1 的真实数据验证：

| 目录 | 内容 | 用途 |
|---|---|---|
| `FLUXSATv2/` | 228 个 NetCDF4（HDF5）文件（每月一个，含逐日 GPP/uncertainty/BRDF_Quality 等变量），3600×7200 | 重采样真实 parity、scaling 基准、filename 模式时间轴 |
| `GLASS-EVI/` | 1012 个 HDF4 HDF-EOS Grid 文件，`evi_0.05` int16 打包，3600×7200 | HDF4-EOS 真实容器验证、打包整数转换、filename 模式 |
| `GOSIF-GPP/` | 1104 个 GeoTIFF（EPSG:4326、0.05°、uint16 单 band，7200×3600） | 真实 GeoTIFF CRS/值域验证、convert 输入覆盖 |
| `MCD12C1/` | 24 个 HDF4 HDF-EOS 分类产品文件，含 Majority_Land_Cover_Type_* 等多分类变量 | 多 band/整数分类数据、HDF-EOS 读取验证 |

使用约束：

- 输入一律只读；临时 Zarr、报告和符号链接写入 `tests/external_data` 或独立工作目录，不写回备份目录。
- 沿用受控窗口策略，优先使用中心窗口和小时间步抽样，不整树转换。
- 真实设备 staging/scaling 基准可在备份目录与输出设备之间读写分离执行。

### 3.2 真实数据与格式验证

### 3.4 native 能力扩展

- [x] **评估 native HDF4 容器读取**
  - 结论：真实 HDF4（GLASS-EVI）容器继续由 Python/netCDF4 compatibility backend 读取，`native_hdf4_supported=false`；
  - v1.8.1 acceptance（case `glass_hdf4_packed_parity`）已记录该 fallback 事实；不扩展 native HDF4 读取。
- [x] **评估剩余重采样方法 native 化**
  - 结论：`patch`、`nearest_d2s` 本周期保持 Python/xESMF 路径，不新增 native capability；
  - FLUXSAT conservative/conservative_normed native parity 已由 v180 acceptance 覆盖；其余方法未通过正确性门禁前不伪装 native 成功。
