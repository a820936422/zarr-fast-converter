## 1. 目标与范围

### 1.1 目标

1. 用 FLUXSATv2 验证 `complete` 模式（源文件自带 time）的真实 NetCDF4 转换正确性，重点覆盖多月拼接、递减纬度与多变量。
2. 用 GLASS-EVI 验证 `filename` 模式（文件名 `AYYYYDOY` 恢复时间轴）的 HDF-EOS 真实数据转换正确性，重点覆盖 `StructMetadata.0` 坐标重建、int16 数值保真与 `backend=auto` 回退记录。
3. 建立受控、只读、可清理的真实数据样本测试流程（沿用 `tests/external_data/` harness）。
4. 对两份数据完成一次全树元数据 + 抽样数值验证（`pixi run validate-raw`），输出可留档 JSON 报告。
5. 可选完成规模/吞吐 A/B（L2），为后续 native 优化或 pipeline 融合评估提供真实数据基线。

### 1.2 范围

- 源数据转换：NetCDF4 / HDF-EOS → Zarr v3，标准维度 `time/lat/lon`。
- 时间轴：`complete` 多文件拼接、`filename` DOY 时间轴恢复。
- 空间坐标：规则 lat/lon 网格、HDF-EOS 无坐标变量重建、递增/递减纬度。
- 数值保真：原始 dtype（float32 / int16）、`mask_and_scale=False` 语义、抽样逐值 parity。
- 规模与吞吐：GLASS 单年、FLUXSAT 单月全网格（可选）。
- 回归门禁：既有全部检查命令保持绿色。

### 1.3 非目标

- 不实现新功能、不改变发布承诺。
- 不做 345 GB FLUXSAT 全量转换（仅抽样 + 可选单月/多文件子集）。
- 不做安装包构建、上传或 GitHub Release。
- 不把真实数据或其输出 Zarr 纳入 Git（全部本地留档）。

## 3. 数据安全与产物策略

- 源数据只读：测试只建立符号链接，不复制、不写入、不删除原始文件。
- 受控样本：默认中心 `32×32` 空间窗口、最多 2 个时间步、固定单 worker。
- 输出位置：全部生成物放 `tests/external_data/`（`inputs/`、`work/`、`results/`、`logs/`）以及本机临时目录；该目录已由 `.gitignore` 排除，不入库。
- 本机清单 `tests/external_data/manifest.local.json` 包含绝对路径，不入库；模板 `manifest.example.json` 入库。
- 大目录快速结构检查（> 阈值 HDF 文件）会触发抽样验证，转换写入时逐文件读取并在不一致时终止发布。

## 5. 用例明细

| ID | 数据 | 模式 | 输入 | 操作/命令 | 通过标准 |
|---|---|---|---|---|---|
| T1 | GLASS-EVI | filename | 2 文件样本 | `pixi run python tests/external_data/run_samples.py` 中 glass 条目；另写断言脚本检查输出 `lat/lon` | 输出 `lat` 为 0.05° 递减规则网格（89.975 → -89.975），`lon` 为 0.05° 递增规则网格（-179.975 → 179.975）；与 `StructMetadata.0` 推导一致；`inventory.lat_values/lon_values` 形状 `(3600,)/(7200,)` |
| T2 | GLASS-EVI | filename | 1012 文件全树 | `pixi run convert -- --mode filename --input /run/media/owen/HDD/数据备份/GLASS-EVI --output <out.zarr> --template doy --year 2001 --doy 001 --step-days 8 --continue-missing --variables evi_0.05 --dry-run`（先 dry-run 扫描） | 时间轴 2001-01-01 → 2022-12-31、8 日步长、无重复/歧义；如存在理论缺口，按 `--continue-missing` 策略补齐并记录；dry-run 报告输出文件数/时间点数正确 |
| T3 | GLASS-EVI | filename | 32×32 窗口样本 | 转换后抽样逐值比对源 `evi_0.05` int16 与输出（`mask_and_scale=False`） | 窗口内逐值完全一致（含 `_FillValue`/`scale_factor` 元数据按现状保留）；`backend=auto` 对 int16 记录明确 fallback reason（native 当前不支持 int16 数据变量） |
| T4 | FLUXSATv2 | complete | 单文件 200101 | `pixi run convert -- --mode complete --input <200101 单文件目录> --output <out.zarr> --variables GPP GPP_uncertainty --lat '[20,50]' --lon '[100,140]'`（或 harness 窗口） | 输出 `time` 为日精度 2001-01-01…2001-01-31；lat/lon 区域映射正确（lat 递增时 `--lat` 与输出切片一致）；窗口内 GPP 逐值 parity |
| T5 | FLUXSATv2 | complete | 200101 + 200102 两月 | 建两文件符号链接目录，`pixi run convert -- --mode complete --input <两月目录> --output <out.zarr> --variables GPP` | 时间轴无 gap/overlap（2001-01-31 → 2001-02-01）；输出文件数/时间点数为 31+28=59；数值在边界日期连续 |
| T6 | 两数据集 | auto | `/run/media/owen/HDD/数据备份/` 根目录 | `pixi run validate-raw -- --input-root /run/media/owen/HDD/数据备份/ --output tests/external_data/results/validate-raw-report.json --smoke-output-root tests/external_data/work/validate-smoke --sample-files 9` | 报告 `file_count` 为 228+1012=1240；两个数据集均通过全文件元数据 + 抽样数值验证；如时间字段歧义，使用 `--time-field GLASS-EVI=INDEX` 覆盖 |

## 9. 风险与回退

- **GLASS 读取依赖 netCDF4 的 HDF4 支持**：已实测可打开；若在低层扫描路径出现后端差异，回退到 xarray 路径并记录 fallback reason。
- **FLUXSAT 345 GB 全量不可行**：仅抽样与单月/两月子集；不承诺全量吞吐。
- **filename 时间字段歧义**：GLASS 文件名含多段数字（版本号、日期、生产日期）；如自动扫描歧义，使用 `--time-field GLASS-EVI=INDEX` 或 manifest `field_values` 显式指定。
- **真实数据产物不入库**：所有输出/日志/清单仅本地留档；重新执行时按本方案重建。
- **远程推送**：v1.7.7 已手动推送远程；v1.7.8 测试改动提交后需按后续指示推送。
