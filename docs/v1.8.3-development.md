## 1. 现状差距（已实证，2026-08-20 勘察）

| # | 差距 | 证据 |
|---|---|---|
| 1 | HDF-EOS 数据内部时间元数据不被解析：MCD12C1 无 time 维度，但 `CoreMetadata.0` 含 RANGEDATETIME（`RANGEBEGINNINGDATE=2001-01-01`、`RANGEENDINGDATE=2001-12-31` 年度覆盖、`PRODUCTIONDATETIME=2022-05-26T17:04:09Z`）；现有 CoreMetadata 解析仅用于 Swath 空间结构 | 备份语料文件属性提取 |
| 2 | filename 自动模板推断在 MCD12C1 目录失败：13 位生产时间戳（`2022146170409`）与观测字段（`A2001001`）并存触发 `_automatic_rule_candidates` 整体歧义拒绝，需手动 `field_values` | `inspect_source(mode=filename)` 实测 FilenameTimeError |
| 3 | 手动模板成功时时间轴仅单日 `2001-01-01`，丢失「年度覆盖 2001-01-01~2001-12-31」语义 | inventory/report 实测 |
| 4 | CF calendar 支持面窄：`_SUPPORTED_CALENDARS={standard,gregorian,proleptic_gregorian,julian}`，noleap/360_day 等在 inspection 即失败 | `inspection.py:127` |

## 2. v1.8.3 目标

1. **从数据内部识别权威时间**：解析 HDF-EOS `CoreMetadata.0` RANGEDATETIME（含生产时间戳），进入 inventory 证据与一致性校验。
2. **文件名自动推断抗歧义**：生产/处理时间戳字段（13/14 位 `YYYYDDDHHMMSS`/`YYYYMMDDHHMMSS`）识别并排除出歧义集，MCD12C1 目录自动模板推断成功。
3. **时间语义正确表达**：覆盖区间（beg~end）与时间尺度进入 inventory/报告，不再把年度产品标成单日。
4. **CF 日历识别面评估**：noleap/360_day 等识别决策明确（支持或明确回退原因）。

## 3. 待办清单

### 3.1 HDF-EOS 数据内部时间识别（重点）

- [x] **CoreMetadata RANGEDATETIME 解析**
  - `_hdf_eos_range_datetime`（PDS 对象语法）解析 `RANGEBEGINNINGDATE/TIME`、`RANGEENDINGDATE/TIME`、`PRODUCTIONDATETIME`；对 HDF 引擎源在 filename inspect 阶段读取参考文件（`engine=="netcdf4"`）。
- [x] **Inventory 证据与一致性**
  - Inventory 新增 `coverage_start/coverage_end`、`internal_time_source("hdf_eos_core_metadata")`，进入 inventory 报告（「数据内部覆盖区间」行）；
  - 文件名推断时间与内部覆盖开始日不一致 → inspection warning（不静默替换，内部时间为权威记录）。

### 3.2 文件名自动推断抗歧义

- [x] **生产时间戳字段识别**
  - `_process_timestamp_positions`：13/14 位 `YYYYDDDHHMMSS`/`YYYYMMDDHHMMSS` 生产时间戳字段从歧义集排除；MCD12C1 目录 `inspect_source(mode="filename")` 自动模板推断成功（template=doy，取观测字段）。
- [x] **内部时间消歧保底**
  - 一致性校验已实现（3.1）；自动推断唯一性场景已覆盖，若仍歧义则维持显式报错（不伪装成功）。

### 3.3 CF 时间元数据与日历识别面

- [x] **日历识别面评估（决策记录）**
  - `_SUPPORTED_CALENDARS` 扩展支持 noleap/365_day/366_day/all_leap（与格里高利刻度 1:1 对齐，仅闰年规则差异，cftime ISO 文本即合法日标签）；
  - **360_day 明确不支持**：12×30 天年度与格里高利刻度无 1:1 映射，标签近似会静默偏移真实时间，保持显式拒绝；
  - 时间尺度识别补强：**年度产品**（每观测年恰好 1 个文件）理论时间轴 = 每年一个观测点（`scan.annual_points`），不再按天逐日枚举（MCD12C1 由 8037 天/8013 缺日修正为 24 年点/0 缺日），frequency 记录「年度（每年一个观测点）」。
- [x] **时间坐标识别补强**
  - 范围评估完成：现有 `time` 变量/CF units/标准 calendar 路径已覆盖；不新增不必要路径（决策记录）。
